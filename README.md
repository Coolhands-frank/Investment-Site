# Investment Site

Welcome to the **Investment Site**, a web platform built with **Next.js, Tailwind CSS, and Supabase** to help users manage their investments efficiently. This platform includes an **admin dashboard** for managing user data and investment records.

## Features
- **User Authentication** (via Supabase Auth)
- **Investment Dashboard** (Track and manage investments)
- **Admin Panel** (CRUD operations for users and investments)
- **Secure Database Integration** (Powered by Supabase)
- **Responsive UI** (Styled with Tailwind CSS)

## Tech Stack
- **Frontend:** Next.js, Tailwind CSS
- **Backend:** Supabase (Database & Authentication)
- **State Management:** Context API
- **API Handling:** Fetch API

## Installation
To set up the project locally, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/Coolhands-frank/Investment-Site.git
   ```
2. Navigate to the project folder:
   ```sh
   cd investment-site
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Set up environment variables:
   - Create a `.env.local` file in the root directory.
   - Add your **Supabase URL** and **Anon Key**:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
5. Start the development server:
   ```sh
   npm run dev
   ```

## Deployment
To deploy the project:
- Use Render or Vercel
- Connect your GitHub repository
- Set environment variables
- Deploy the project with one click
